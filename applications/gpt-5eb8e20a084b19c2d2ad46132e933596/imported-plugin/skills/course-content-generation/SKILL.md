# Course Content Generation

Own WF-03 and IM-05 Course Content.

## Required sources
Consult complete local copies of RM-01 `AI Pedagogy Rulebook.md` and RM-05 `Course-Content-Generation-Logic.md` before dependent content decisions. RM-06, RM-04-New, RM-11/RM-12 become required only when their specific Section 13 triggers occur. When capability/application routing is activated, consult RM-04-New through `thinking-first-reference-integrity/references/AI-Application-Routing-Authority.md`. Module-level dependency summaries do not make conditional references universal.

## Behavior
- Analyze the supplied module/course before generating full teaching material.
- Extract knowledge points first; treat the knowledge point as the minimum generation unit.
- For each knowledge point provide at least explanation, teacher reminder, common misunderstanding, and thinking prompt when consistent with RM-05.
- Preserve the teacher as instructional authority. AI is a support tool, not the final authority.
- Do not silently replace specialized source authority with generic model knowledge.
- If a requested later artifact skips required analysis, provide only a provisional draft with assumptions disclosed.
