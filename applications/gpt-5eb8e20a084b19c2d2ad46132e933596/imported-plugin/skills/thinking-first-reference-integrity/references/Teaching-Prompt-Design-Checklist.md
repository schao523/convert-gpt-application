✅ 教學 Prompt 設計檢查清單
------------------

（Teaching Prompt Design Checklist）

> **使用方式**  
> 每一個教學 prompt 或 AI practice prompt，在輸出前必須逐條檢查。  
> 若任一項未通過，應先修正 prompt，再進行使用或輸出。

* * *

### 1️⃣ 認知負荷檢查（Cognitive Load）

**檢查問題：**

* 此 prompt 是否一次只要求學生進行「一項主要認知任務」？

* 是否避免同時要求學生：
  
  * 學習新內容
  
  * 操作新工具
  
  * 進行反思或產出？

**通過標準：**

* 能清楚用一句話說明：
  
  > 「學生在這個 prompt 中，主要被要求思考的是什麼？」

* * *

### 2️⃣ 形成性掙扎檢查（Desirable Difficulty）

**檢查問題：**

* 此 prompt 是否刻意保留尚未完成或尚未解決的空間？

* 是否避免直接要求：
  
  * 完整答案
  
  * 總結性結論
  
  * 最佳解法？

**通過標準：**

* 完成此 prompt，不等於問題已被完全解決。

* 學生仍被鼓勵保留疑問與張力。

* * *

### 3️⃣ 教學時機檢查（Instructional Timing）

**檢查問題：**

* 此 prompt 是否清楚規定「AI 何時可以介入」？

* 是否要求學生先完成必要的表達（觀察、想法、設計理由）？

* 是否限制 AI 不得提早給建議或結論？

**通過標準：**

* AI 的介入是被學生行為觸發的，而非自動發生。

* * *

### 4️⃣ 學生輸出品質檢查（Quality Threshold）

**檢查問題：**

* 此 prompt 是否清楚定義「什麼樣的學生回應才算完成」？

* 是否要求學生提供至少一項：
  
  * 理由（why）
  
  * 例子（example）
  
  * 限制或保留（limitation）？

**通過標準：**

* 學生必須具體說明自己的思考，而非僅做表面回應。

* * *

### 5️⃣ 反思完成點檢查（Reflection as Completion）

**檢查問題：**

* 此 prompt 的最終步驟是否回到學生的反思與判斷？

* 是否避免將「AI 產出完成」視為學習完成？

* 是否要求學生評估、修正或限制 AI 的角色？

**通過標準：**

* 學習的完成點是人的反思，而不是工具的成功。

* * *

🧠 設計原則總結
---------

> **好的教學 prompt，不是幫學生更快完成任務，  
> 而是確保學生在「該自己思考的地方，無法跳過思考」。**
