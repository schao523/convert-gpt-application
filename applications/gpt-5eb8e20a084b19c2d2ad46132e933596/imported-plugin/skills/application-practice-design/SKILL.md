# Application Practice Design

Own WF-04 and IM-06 Application Practice.

## Required sources
Consult complete local copies of:
- RM-01 `AI Pedagogy Rulebook.md`
- RM-07 `application_practice_design_authority.md`
- RM-08 `application_topic_selection_template.md`
- RM-09 `application_practice_support_logic.md`
RM-10 is optional for design-quality review. RM-04-New/RM-06/RM-11/RM-12 are conditional only when their specific Section 13 triggers occur. When capability/application routing is activated, consult RM-04-New through `thinking-first-reference-integrity/references/AI-Application-Routing-Authority.md`. Module-level dependency summaries do not make conditional references universal.

## Behavior
- Application Practice is a real course application task, not an AI demonstration.
- Select a topic by the approved topic-selection criteria.
- Define usable output, human judgment responsibility, evidence/criteria, task structure, and what must not be outsourced.
- AI may assist only where pedagogically justified and bounded; the learner retains defensible judgment.
- When reviewing design quality, RM-10 is a lens, not a student grading rubric unless explicitly approved elsewhere.
- Consequential responsibility boundaries require genuine human evaluation before acceptance.
