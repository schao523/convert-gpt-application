# Application Topic Selection Template

## 目的
本模板用於協助教師或 GPT 篩選**適合發展為 Application Practice 的應用主題**，避免將活動、工具示範或 AI 操作誤認為課程應用。

---

## 使用方式
請針對候選的 application topic，逐題回答以下問題。

- 若多數回答為「否」，該主題**不適合**作為 Application Practice。
- 若大多數回答為「是」，可進入 Application Practice 設計階段。

---

## 一、風險導向檢查（Risk-based）

1. ❓ 若學生無法完成此任務，是否會在真實情境中造成實際問題或誤用？
2. ❓ 此能力是否屬於本課程「不可缺席」的學習責任？

---

## 二、判斷導向檢查（Judgment-based）

3. ❓ 完成此任務是否需要學生做出關鍵判斷，而非只是依指示操作？
4. ❓ 是否存在多種合理做法，而學生必須為其選擇負責？

---

## 三、情境導向檢查（Context-based）

5. ❓ 此任務是否對應一個真實世界的使用情境（教學、牧養、研究、行政等）？
6. ❓ 該情境是否為學生未來可能實際面對的角色與責任？

---

## 四、AI 依賴排除檢查（Exclusion）

7. ❓ 若完全不使用 AI，學生是否仍能完成此任務？

- 若回答為「否」→ 此主題**不應**作為 Application Practice。

---

## 五、快速判斷結論

- ✔ 通過 5 題以上 → 適合發展為 Application Practice
- ⚠ 通過 3–4 題 → 需調整後再評估
- ✖ 通過 2 題以下 → 不建議使用

---

## 常見不合格主題（參考）

- 僅示範 AI 工具功能
- 僅完成表面產出，無需判斷
- 純活動體驗，無課程責任
