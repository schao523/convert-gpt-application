# Vibe Coding Designer Compatibility

Routine requests should use one of the seven focused skills directly. Use the
[lookup index](lookup/knowledge-index.json) to select the skill whose declared
goal matches the request.

Select the simplest software form that satisfies the goal; never assume a Web GUI is required.
Produce design material rather than implementing the designed application, and
never claim execution or verification without evidence.

When more than one focused skill applies, preserve the user's approved
decisions and proceed from discovery toward specifications, workflows,
implementation guidance, tests, review, or a repository development package.
