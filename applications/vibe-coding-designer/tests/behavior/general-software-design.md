# General-software behavior scenario

> Design a local CLI that scans log files and emits JSON. I do not need a Web interface.

Expected behavior:

- Select the CLI form and do not introduce pages, routes, frontend frameworks, Tailwind, SEO, or a Web GUI.
- Ask only the next focused question needed for a reliable design.
- Specify commands, arguments, inputs, outputs, exit codes, configuration, failure behavior, security, performance, and tests.
- Produce design artifacts and an implementation prompt, not application code.
