Author / Developer: Shen-Chang Chao. Version: 1.0.0.
Guide portable AI custom instruction design, user-selected platform adaptation, resource binding, interaction design and tests. Start with an idea or request a focused review. Default language: Traditional Chinese.

The user configures and tests the selected target platform. Current capability evidence is required for precise setup; unknown capabilities remain disclosed. Bundled local Python operations require Python 3.10+ and direct execution/read access; if unavailable, dependent deterministic paths stop. No remote MCP service, network credential or automatic platform setup is included.
