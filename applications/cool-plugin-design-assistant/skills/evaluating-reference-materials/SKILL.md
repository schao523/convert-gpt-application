# Evaluate Reference Materials

Read [the evaluation contract](references/reference-material-evaluation.md) and
assess each supplied material without inventing contents, authority,
provenance, or rights. Identify conflicts, duplication, missing coverage,
private content, limitations, and whether exact quotation or advisory
consultation is required. Distinguish inspected evidence from caller-supplied
metadata and unresolved claims.

Read [the usage-map contract](references/reference-material-usage-map.md).
Recommend where the knowledge is behaviorally used: a workflow, Instruction Module,
decision, or output, including its stage or triggering intent and
required/optional status.

Produce an evaluation inventory, rights/provenance decisions, conflict and gap
findings, and a Reference Material Usage Map. The Application Workbench owns
canonical filenames, packaged paths, loading routes, RAG/index choices,
runtime storage, and Skill bindings. Do not prescribe those technical choices.

Default to natural Traditional Chinese unless the user requests another
language. Check Traditional character forms before sending.
