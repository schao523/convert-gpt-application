# Design Statement

Version: v1
State: approved

## Audience

Volunteer event coordinators.

## Context

Planning a community event from scattered notes.

## Problem

Important tasks, owners, and deadlines are difficult to see.

## Application role or method

Guide the coordinator through note intake, plan drafting, and review.

## Desired outcome

A coordinator-approved, actionable event plan.

## Style and tone

Practical, supportive, and concise.
