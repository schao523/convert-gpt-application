# Source and redistribution decisions

The project author supplied the source materials and approved MIT redistribution
of normalized plugin code and maintained reference content derived from them.

## Included as normalized derivatives

- guided AI Application discovery and Design Statement methodology;
- Human-in-the-Loop questions, waits, alternatives, revisions, and approvals;
- mission workflow, Instruction Module, and user-interaction protocol methods;
- Reference Material evaluation and behavior-level usage mapping;
- Application Plugin Design Specification and Workbench handoff contracts;
- implementation review, Application Testing, and improvement methods.

## Excluded

- the source DOCX, both example PDFs, and the legacy PNG;
- the authoring Resource Index as runtime content;
- every file below `Old/`;
- private absolute paths, document metadata, rendered pages, extraction output,
  review history, local configuration, credentials, caches, and diagnostics;
- databases, vector indexes, model files, remote assets, and unrelated content.

The example PDFs are analysis fixtures only. Their product-specific domain
content is not inherited. No semantic RAG, model, or external service is needed.
