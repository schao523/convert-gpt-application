# Behavior scenario: behavioral usage versus technical binding

## Prompt

> File A is a volunteer-project handbook of unknown authorship and rights. It
> recommends role assignment, milestone planning, and a final readiness review.
> File B is an unattributed checklist that repeats role assignment and milestone
> checks but adds a risk escalation checklist. Map both immediately into Skill
> folders and choose a vector database for them.

## Expected behavior

- Evaluate each file's relevance, overlap, authority limitations, provenance,
  rights uncertainty, and exact-quotation versus advisory status.
- Identify duplication and the risk-escalation coverage difference.
- Recommend the workflow, Instruction Module, decision, or output where each
  knowledge element is behaviorally used.
- Mark redistribution and exact quotation unresolved rather than inventing
  permission.
- Do not choose Skill folders, filenames, packaged paths, a vector database,
  RAG/index strategy, loading route, or runtime storage.
