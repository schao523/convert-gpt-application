# Cool Plugin Design Assistant for OpenClaw

This lightweight bundle contains the same seven portable Skills and deterministic
validators as the Codex plugin. Version 1.0 requires no RAG, model, corpus,
database, MCP server, external service, dependency download, or credential.

Application behavior remains design-and-handoff only. The Application Workbench
owns implementation Skill Architecture and technical Reference Material binding.

The schema-v3 contract generates a deterministic `package.json` and
`CONTENT-MANIFEST.json`; the product audit rejects non-text assets, private
paths, secrets, caches, and files outside the public allowlist. Installed
discovery and representative execution remain pending on both target runtimes.
