# Cool Plugin Design Assistant for OpenClaw

This lightweight bundle contains the same seven portable Skills and deterministic
validators as the Codex plugin. Version 1.0.3 requires no RAG, model, corpus,
database, MCP server, external service, dependency download, or credential.
The package includes the declared `plugin_authoring` and `workbench_handoff`
framework modules for standalone Source Handoff preflight and normalization.

Application behavior remains design-and-handoff only. The Application Workbench
owns implementation Skill Architecture and technical Reference Material binding.

The schema-v3 contract generates a deterministic `package.json` and
`CONTENT-MANIFEST.json`; the product audit rejects non-text assets, private
paths, secrets, caches, and files outside the public allowlist. Installed
discovery and packaged deterministic commands are runtime-verified in
OpenClaw and Codex. The matched Design Statement scenario is runtime-verified;
the remaining approved representative-scenario suite and full staged
marketplace delta remain `NOT VERIFIED`, so the conversion is not `READY`.

Version 1.0.3 adds Source Handoff preflight for the Chat-to-Work transfer.
The 1.0.3 artifact needs its own installed discovery and execution evidence;
the observations above describe earlier releases.
