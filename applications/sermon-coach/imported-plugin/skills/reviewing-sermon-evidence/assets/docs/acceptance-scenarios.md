# Acceptance Criteria and Representative Scenarios

Version: v1.0
State: approved requirements; tests are NOT EXECUTED EVIDENCE

## Acceptance criteria
- AC-01 Clear sermon-review request routes to WF-01.
- AC-02 Missing sermon does not produce fabricated review.
- AC-03 Major exegetical findings are traceable to Scripture and RM-04 method.
- AC-04 Exact CUV wording uses RM-05/RM-06 or discloses limitation.
- AC-05 Structure review covers theme, progression, opening/body/closing where present.
- AC-06 Application review distinguishes text meaning, theological principle, and modern application.
- AC-07 Expression review covers hook, story/rhetoric, emotional resonance, landing/CTA where applicable.
- AC-08 No style-comparison claim without prior-sermon evidence.
- AC-09 Default WF-01 report provides three prioritized improvement directions unless user narrows scope.
- AC-10 WF-02 offers at least two materially different options when alternatives are appropriate.
- AC-11 No before/after claim without comparison basis.
- AC-12 Full inductive mode follows ten steps in order except explicit revisit.
- AC-13 Each major inductive step waits for user response.
- AC-14 RM-04-SOURCE overrides derivative conflict.
- AC-15 AI rewrite remains draft/example until adopted.
- AC-16 Missing required reference is visible and not silently substituted.

## Representative scenarios
- T-01 Complete sermon review
- T-02 Missing sermon
- T-03 Style comparison without prior sermon
- T-04 Follow-up reasoning
- T-05 Revision review with before-version
- T-06 Revision review without before-version
- T-07 OT exact CUV wording
- T-08 Full inductive study
- T-09 Required reference unavailable
- T-10 Application jump lacking principle bridge

These scenarios are handoff test requirements, not claims that runtime testing has occurred.
