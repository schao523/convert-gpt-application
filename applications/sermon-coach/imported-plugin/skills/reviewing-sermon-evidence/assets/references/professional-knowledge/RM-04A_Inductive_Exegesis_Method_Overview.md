# RM-04A — Inductive Exegesis Method Overview

Source family: RM-04《歸納釋經法》  
Source authority: `歸納釋經法(1).pdf`  
Knowledge type: Professional knowledge derivative  
Primary behavioral use: IM-02 Scripture & Exegesis Review; IM-10 Inductive Scripture Study  
Use mode: Advisory  
Transformation rule: Preserve the source method, terminology, sequence, and distinctions; do not add external methodology as if it came from the source.

## 1. 方法定位

《歸納釋經法》把「方法」視為研讀聖經的工具與路徑。方法提供系統性的程序、法則與步驟，使研經者有路可循、有法可用；但方法本身不應成為「主人」。方法的作用是服事研經者，使其能更有秩序、更有效率地理解經文，而不是把研經限制在僵化程序之中。

## 2. 核心架構

本方法將歸納式查經與釋經學原理結合，採用三大架構：

1. **觀察（Observation）**
   - 第一步：細察事實
   - 第二步：認清關係
   - 第三步：注意結構

2. **解釋（Interpretation）**
   - 第四步：勤發問題
   - 第五步：逐題解答
   - 第六步：歸納總意
   - 第七步：找出主題

3. **應用（Application）**
   - 第八步：寫下原則
   - 第九步：列出細節
   - 第十步：身體力行

## 3. 方法的重要邏輯

- 觀察不是解釋；要先看見經文實際出現的內容，再進入意義判斷。
- 解釋不是零散回答問題，而是逐步把觀察所得組合成整體意義、總意與主題。
- 應用不是直接從某節經文跳到今日行動；必須先找出經文主題，再形成超越時空的神學原則，然後轉成具體實踐。
- 方法同時使用歸納與演繹：既保留歸納式查經的易學性，也使用釋經原則補強解釋。
- 經文應用必須建立在正確解釋之上。

## 4. 十步總覽

| 階段 | 步驟 | 核心工作 |
|---|---|---|
| 觀察 | 1. 細察事實 | 找出人、事、物、文體、關鍵字、命令、應許等經文事實 |
| 觀察 | 2. 認清關係 | 找出上下文、高潮、對比、重複、語法、時間與地域等關係 |
| 觀察 | 3. 注意結構 | 從整體掌握段落、主題句、事件佈局與文思結構 |
| 解釋 | 4. 勤發問題 | 提出定義性、邏輯性、引申性問題 |
| 解釋 | 5. 逐題解答 | 運用解經原則，逐一回答經文問題 |
| 解釋 | 6. 歸納總意 | 整合答案，形成一兩句整體意義並整理結構大綱 |
| 解釋 | 7. 找出主題 | 用完整句子表達整段經文的神學性核心命題 |
| 應用 | 8. 寫下原則 | 將主題轉成超越時空、與整體聖經相符的神學原則 |
| 應用 | 9. 列出細節 | 把原則轉成具體、可衡量、可達成、相關、有時間性的行動 |
| 應用 | 10. 身體力行 | 即時實行、持續提醒、自我省察並尋求屬靈伙伴督促 |

## 5. Plugin 使用規則

### IM-02 Scripture & Exegesis Review
當 Plugin 評估講章中的經文使用時，應依此方法檢查：
- 講章是否先尊重經文本身的觀察資料；
- 解釋是否符合上下文、結構與其他釋經原則；
- 講章主題是否真的來自經文；
- 應用是否經過「主題 → 神學原則 → 生活細節」的合理橋接。

### IM-10 Inductive Scripture Study
當使用者要求查經時：
- 簡化模式可使用「觀察—解釋—應用」。
- 完整模式應按十步依序進行。
- 每一步應根據當步驟的原則形成問題，引導使用者自行觀察、回答與判斷。
- 不應在使用者尚未完成當前步驟時，預先替他完成後續所有步驟。

## 6. 不應做的事

- 不把方法本身當成經文權威。
- 不跳過觀察直接進入應用。
- 不以模型既有知識替代來源中明確的方法規則。
- 不把應用寫成與經文主題無關的一般勵志建議。
