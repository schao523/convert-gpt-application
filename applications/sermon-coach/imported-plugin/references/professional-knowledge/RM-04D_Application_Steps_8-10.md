# RM-04D — Application Steps 8–10

Source family: RM-04《歸納釋經法》  
Primary behavioral use: IM-02; IM-04; IM-10  
Scope: 十步法之應用階段  
Use mode: Advisory

## Step 8 — 寫下原則

目的：把經文主題轉成超越時空、與聖經整體教導相符、可以應用的神學原則。

### 核心觀念

**「原則」是解釋與應用之間的橋樑。**

流程：

`經文對原讀者的意義 → 主題 → 神學原則 → 今日重要性與行動`

原則必須：
- 根據經文主題；
- 根據聖經整體神學；
- 不是人的思想性格；
- 超越特定時空限制；
- 具有恆久性價值。

### 神學原則應用法

1. 先檢查經文主題是否受文化或語義差距限制。
2. 若有文化限制，先辨明哪些是時代性表現、哪些是恆久性意義。
3. 寫出初步神學原則。
4. 第二重檢查：此原則是否與聖經其他教導相符。
5. 把經過檢驗的神學原則轉成今日信徒可以理解與實行的屬靈教訓。
6. 再進入生活反思與行動。

### 文化差距注意事項

要分辨：
- 是否是與神心意有關的道德真理；
- 是否只是當時風俗；
- 是否是普遍原則，或只是某原則的歷史性例子；
- 是否針對當時某種流弊；
- 是否只適用於某一時代、後來已有進一步教導。

不應迫不及待直接應用，而忽略經文原意與文化差距。

## Step 9 — 列出細節

目的：把普遍的神學原則轉化成具體可實行的生活方案。

### 原則與細節的區別

- **原則**：普遍性，可跨情境。
- **細節**：具體性，適用於實際處境。

### SMART 特質

- **S — Specific**：具體。
- **M — Measurable**：可衡量。
- **A — Achievable**：可達成。
- **R — Relevant**：與經文意義及實際需要相關。
- **T — Timing-related**：有時間性。

### 應用角度

- 神學、對人、對己；
- 知識、態度、行動；
- 團體或個人；
- 生活、人格、工作、社會參與。

## Step 10 — 身體力行

目的：把所理解的經文與已列出的應用真正付諸行動。

### 行動原則

1. 行動要即時。
2. 經常自我提醒。
3. 自我省察、檢討、校正。
4. 以禱告求主加力。
5. 可背誦經文，使真理持續提醒自己。
6. 可請屬靈伙伴督促與提醒。

## IM-04 與 IM-10 使用規則

### IM-04 Application & Audience Review
檢視講章應用時，需區分：
- 經文本身的主題；
- 經文化成的普遍神學原則；
- 對今日聽眾的具體應用。

若講章從古代事件直接跳到現代行動，而沒有合理的神學原則橋接，應指出此問題。

### IM-10 Inductive Scripture Study
不可只問「你今天要怎麼應用？」；應先完成：
`主題 → 神學原則 → 文化／時代檢查 → 聖經整體一致性 → 具體行動`

具體應用可以鼓勵 SMART，但必須避免把屬靈成長機械化為單一量化指標。
