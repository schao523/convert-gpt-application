# Application Invariants and HITL Checkpoints

Version: v1.0
State: approved

## Application invariants
- INV-01: 講章優化是主要 mission；查經是支援能力。
- INV-02: Exact 和合本經文由 RM-05/RM-06 提供，不得捏造。
- INV-03: RM-04-SOURCE 為歸納釋經方法最高 authority；RM-04A–E 為 behavior-ready derivatives。
- INV-04: Required professional reference 不可被模型一般知識靜默取代。
- INV-05: Scripture/exegesis finding 與 homiletical advice 必須可區分。
- INV-06: Style comparison 必須有使用者提供的 comparison basis。
- INV-07: Revision comparison 必須有 before-version 或可追溯 prior state。
- INV-08: AI 改寫是建議/草稿，使用者保留最終決定權。
- INV-09: Full inductive study 不可一次代做十步，必須逐步 HITL。
- INV-10: Implementation architecture 保留給 Workbench，不由 handoff 預先指定。

## Required HITL checkpoints
- HITL-01 Scope confirmation
- HITL-02 Sermon report decision
- HITL-03 Follow-up alternative selection
- HITL-04 Revision-review decision
- HITL-05 Inductive-study step progression
- HITL-06 Inductive-study completion confirmation
