# Cinematic Direction & Quality

Translate approved story intent into scene-level cinematic direction: shot language, composition, Start Frames, lighting/mood, acting, dialogue delivery, sound/music cues, and visual rhythm. Preserve scene identity so downstream production remains traceable.

## Reference requirements
Camera/composition/lighting work requires consultation of RM-C02, RM-C03, and RM-C04. Character performance uses RM-C05; sound/music uses RM-C06; dialogue delivery uses RM-C07. Rhythm audits use RM-C01. Style-specific decisions use RM-C08. Quality review uses the applicable Bible or Inspirational rubric plus the relevant cinematic references for dimensions being judged.

## Quality workflow
Evaluate before revising. Explain deficiencies and practical changes. Never silently change approved theological/moral intent, scene meaning, or canonical project state. If a revision alters canonical intent, route back through the Director approval/state path.

## Requirement ownership
REQ-002, REQ-006, REQ-016, REQ-018, REQ-021, REQ-022, REQ-023, REQ-024, REQ-025
