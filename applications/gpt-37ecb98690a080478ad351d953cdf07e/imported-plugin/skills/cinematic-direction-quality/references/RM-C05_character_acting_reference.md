# 🎭 Character Acting Reference.md  
*(角色表演與情緒演出指南 — Character Acting & Emotion Expression Guide)*  

---

## 🎯 目的（Purpose）  
幫助 Director GPT 在分鏡與語音設計階段，準確描繪角色的表情、姿態與情緒變化，  
使故事角色更生動、有層次，並與鏡頭語言與配樂節奏同步。  

---

## 🧱 一、表演層級（Acting Layers）

| 層級 | 類別 | 說明 | 範例 |
|------|------|------|------|
| 🧍‍♂️ **肢體動作（Body Movement）** | 大動作（Macro Motion） | 行走、奔跑、舉手、跪下、擁抱 | 「大衛挺身而出」、「門徒跪地祈禱」 |
|  | 微動作（Micro Gesture） | 手勢、轉頭、眼神交流、呼吸變化 | 「眼神閃爍，手指微顫」 |
| 😐 **表情控制（Facial Expression）** | 情緒表現 | 喜、怒、哀、懼、驚、信、平靜 | 「眉頭微皺、嘴角緊閉，壓抑的恐懼」 |
| 💭 **心理內涵（Inner Emotion）** | 內在情感與信念 | 信任、懷疑、希望、悔改 | 「他心中閃過懷疑，隨即被信心取代」 |
| 🎙️ **語氣與節奏（Voice & Tempo）** | 語速、音量、停頓、重音 | 「低聲呢喃」、「強而有力地宣告」 |
| 🫶 **關係互動（Interaction Cues）** | 與他人或群體的動態關係 | 「對望」、「轉身避開」、「攙扶彼此」 |

## 🎨 二、情緒類型與演出建議（Emotion Expression Guide）

| 情緒 | 肢體表現 | 面部表情 | 語音與節奏 | 建議鏡頭 |
|------|------------|------------|---------------|------------|
| 信心 / 勇氣 | 胸膛挺起、步伐堅定 | 目光堅毅 | 穩重語氣、節奏緩升 | 低角度推進 |
| 恐懼 / 懷疑 | 肩膀緊縮、退後 | 眼神閃爍、嘴微張 | 語速急促、聲音顫抖 | 俯拍或側光 |
| 喜樂 / 感恩 | 雙手舉起、笑容綻放 | 臉部放鬆 | 音量漸強、節奏輕快 | 平移或旋轉環繞 |
| 憂傷 / 悔改 | 身軀彎曲、淚眼低垂 | 嘴角下沉 | 語速緩慢、低聲 | 近景特寫 |
| 敬畏 / 讚歎 | 雙手合十、抬頭仰望 | 驚嘆或平靜微笑 | 語調柔和、帶回音 | 逆光或光暈構圖 |
| 憤怒 / 對抗 | 緊握拳頭、前傾 | 眉頭深皺、咬牙 | 語音急促、節奏斷裂 | 快速推進、動態鏡頭 |
| 平安 / 釋放 | 深呼吸、緩慢步伐 | 眼神平靜、微笑 | 語速平穩、柔聲 | 拉遠或俯拍收尾 |

## ⚙️ 三、使用原則（Usage Guidelines）

1️⃣ **每幕至少設定一種主情緒**  
> 例：「信心與恐懼的交錯」，可產生情感張力。  

2️⃣ **情緒應隨劇情節奏自然轉換**  
> 節奏加快 → 情緒更強烈；  
> 節奏放緩 → 情緒內省化。  

3️⃣ **肢體、表情與語音需一致**  
> 避免「身體表達」與「語音語氣」不符。  

4️⃣ **整合鏡頭與光影語言**  
> 不同情緒對應不同光線與角度：  
> - 喜樂 → 柔光 + 高飽和色  
> - 悔改 → 低光 + 冷色  
> - 信心 → 逆光 + 金色光暈

## 📖 四、範例（Example Integration）

> 🎞️ Scene 4：彼得悔改  
> 【表演】彼得跪地掩面，肩膀顫抖，眼淚滑落。  
> 【表情】痛苦中帶懺悔，目光閃爍卻渴望赦免。  
> 【語音】低聲呢喃：「主啊，離開我這罪人。」  
> 【光影】微光穿透陰暗，象徵恩典臨到。
