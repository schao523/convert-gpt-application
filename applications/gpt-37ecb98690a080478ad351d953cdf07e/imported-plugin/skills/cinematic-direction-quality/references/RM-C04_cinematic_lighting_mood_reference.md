# 💡 Cinematic Lighting & Mood Reference.md  
*(光影與情緒控制指南 — Lighting & Mood Design Guide)*  

---

## 🎯 目的（Purpose）  
協助 Director GPT 為每幕分鏡與 Start Frame 描述設計對應的光影與色調，  
以建立情緒氛圍、時間感與屬靈象徵。  

此文件將幫助 GPT 在畫面生成提示中自然加入光影語言（如「柔光、逆光、夕陽餘暉、神聖光暈」），  
讓輸出更具電影感與神學象徵深度。

## 🧱 一、光影類型與敘事用途（Lighting Types & Narrative Use）

| 類別 | 名稱 | 效果與用途 | 常見應用情境 |
|------|------|-------------|--------------|
| 🌅 自然光（Natural Light） | **Soft Morning Light** | 柔和金色光線，象徵新開始與希望 | 清晨祈禱、救贖場景 |
|  | **Sunset Glow** | 橙紅色斜陽，寓意結束、反思或恩典 | 晚禱、結尾、釋放 |
| 🌙 夜間光（Night Light） | **Moonlight / Cool Blue Tone** | 藍灰色冷調，表現孤寂或敬畏 | 夜間默想、掙扎、警醒 |
|  | **Candle / Firelight** | 溫暖跳動光源，帶出人性與團契感 | 圍爐、家庭、信心堅持 |
| 🔦 方向光（Directional Light） | **Spotlight / Beam Light** | 強調焦點與啟示時刻 | 神聖顯現、呼召場景 |
|  | **Side Lighting** | 一側光，營造對比與張力 | 掙扎、矛盾、選擇 |
| 🕯️ 象徵光（Symbolic Light） | **Backlight / Halo Light** | 從後方透光，象徵聖潔與覺醒 | 禱告、覺悟、復活 |
|  | **Rim Light / Edge Glow** | 輪廓光突出人物 | 強調信心堅定、靈光時刻 |
| 🌫️ 氣氛光（Atmospheric Light） | **Fog / Mist Light** | 模糊邊界，營造神秘與信心試煉 | 曠野、異象、預言 |
|  | **Rain Reflection / Wet Surface Light** | 光線反射水面 | 懺悔、洗淨、重生 |

## ⚙️ 三、使用原則（Usage Guidelines）

1️⃣ **光影應支撐情感節奏**  
> 當故事節奏上升（緊張 / 啟示），光線強度應提升。  
> 當節奏放緩（反思 / 禱告），光線可柔化或減弱。  

2️⃣ **避免光影衝突**  
> 同一幕中應保持光源方向一致，避免混亂或違反物理邏輯。  

3️⃣ **與 Auto-Rules 同步風格**  
> 若風格為兒童卡通 → 使用明亮飽和色。  
> 若風格為寫實劇情 → 使用自然光與柔焦。  
> 若風格為靈修短片 → 使用柔光與高對比象徵性照明。  

4️⃣ **AI 畫面提示語建議**  
> - soft golden sunrise lighting, cinematic volumetric rays  
> - dramatic backlight halo, divine glow  
> - moody blue twilight, fog with depth, reflective wet ground  
> - contrast side light, warm candle tone
