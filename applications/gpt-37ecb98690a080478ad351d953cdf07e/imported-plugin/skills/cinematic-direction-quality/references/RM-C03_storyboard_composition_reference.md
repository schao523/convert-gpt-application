# 🎞️ Storyboard Composition Reference.md  
*(分鏡構圖參考指南 — Cinematic Shot Composition Guide)*  

---

## 🎯 目的（Purpose）  
提供 Director GPT 對應各種情境的鏡頭構圖參考，  
以便在生成分鏡腳本與運鏡說明時，能選擇適合的鏡頭角度與情緒語言，  
提升畫面節奏與敘事張力。  

---

## 🧱 分類一覽（Composition Categories）

| 類別 | 構圖名稱 | 說明 | 適用情緒與用途 |
|------|-----------|------|----------------|
| 🎬 開場與轉場 | **Establishing Shot** | 寬景展示整體環境與氛圍 | 建立場景位置與氛圍（例：城市、山谷） |
|  | **Extreme Wide Shot (EWS)** | 超廣角遠景，顯示角色與環境比例 | 渺小感、史詩感、命運感 |
|  | **Aerial Shot / Bird’s-eye View** | 高空俯拍，展現全貌或轉場 | 全景導入、空間關係、戰爭場面 |
| 🎭 角色視角 | **Medium Shot (MS)** | 角色腰部以上，聚焦對話與情緒 | 對話場景、溝通、思考 |
|  | **Close-Up (CU)** | 角色臉部表情特寫 | 情感強化、恐懼、信心、覺悟 |
|  | **Extreme Close-Up (ECU)** | 聚焦眼睛、手、物件細節 | 象徵、強烈情緒、焦點轉換 |
|  | **Over-the-Shoulder (OTS)** | 從角色背後構圖，展示對話對象 | 對話張力、關係對比 |
|  | **Point-of-View (POV)** | 模擬角色視角 | 內心體驗、身歷其境 |
| ⚔️ 動作與衝突 | **Low Angle Shot** | 自下而上拍攝，強調力量與威勢 | 英雄登場、巨人、勝利 |
|  | **High Angle Shot** | 自上俯視角色，表現脆弱或懼怕 | 軟弱、壓迫、失敗 |
|  | **Tracking Shot / Dolly Move** | 鏡頭平行跟隨角色 | 追逐、冒險、行動連貫性 |
|  | **Handheld / Shake Cam** | 模擬人手晃動 | 緊張、混亂、戰鬥場面 |
| 🌅 情感與象徵 | **Silhouette Shot** | 逆光拍攝，只見輪廓 | 信仰、孤獨、希望象徵 |
|  | **Reflection Shot** | 透過鏡子、水面反射 | 內省、雙重身份、屬靈反思 |
|  | **Dutch Angle (Tilted Shot)** | 鏡頭傾斜 | 不安、衝突、內在掙扎 |
|  | **Backlight / Halo Shot** | 背光構圖、光暈 | 神聖、覺醒、靈光時刻 |
| 💫 群體與情節節奏 | **Two-Shot / Group Shot** | 兩人或多人同框 | 關係、群體互動、團契 |
|  | **Cut-in / Insert** | 插入物件細節 | 象徵、轉場、暗示 |
|  | **Rack Focus** | 對焦轉換於前後景 | 關注轉移、焦點變化 |
|  | **Montage Sequence** | 快速多鏡頭剪輯 | 時間流逝、情緒堆疊、成長過程 |

## ⚙️ 使用建議（Usage Guidelines）

1️⃣ **每幕分鏡至少包含一種構圖類型**  
> 有助 GPT 在場景描述中自然融入視覺語言，例如：  
> 「中景推進至角色表情特寫，聚焦他眼中的信念。」  

2️⃣ **與 Camera Techniques Glossary 結合使用**  
> 本文件決定「構圖框架」；  
> `Camera Techniques Glossary.md` 決定「鏡頭運動」；  
> 兩者結合能產生自然的分鏡連貫性。  

3️⃣ **根據 Visual Rhythm Support Module 調整構圖頻率**  
> 節奏 Level 高 → 多使用動態鏡頭構圖（Tracking / Dolly）。  
> 節奏 Level 低 → 停留於長鏡頭與特寫強調內省。
