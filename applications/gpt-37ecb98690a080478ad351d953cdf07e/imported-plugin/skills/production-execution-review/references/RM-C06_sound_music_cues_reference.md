# 🎵 Sound & Music Cues Reference.md  
*(音效與配樂提示參考指南 — Sound & Music Cue Reference Guide)*  

---

## 🎯 目的（Purpose）  
幫助 Director GPT 在生成動畫分鏡與運鏡腳本時，  
同時設計「聲音層」的表達，  
包括環境音效（Sound FX）、角色聲音（Voice）、以及配樂（Music）。  

此指南可應用於：  
- 動畫／影片腳本（Script）  
- 靈修或啟發式故事旁白  
- 教學影片的音畫設計  

---

## 🧱 一、聲音層級分類（Sound Layer Categories）

| 類型 | 子分類 | 說明 | 範例 |
|------|---------|------|------|
| 🎧 環境音效（Ambient FX） | 自然環境聲 | 風聲、雨聲、鳥鳴、海浪、營火聲 | 「微風拂過樹林」、「遠處雷聲隆隆」 |
|  | 城市環境聲 | 車流、人聲、鐘聲、喇叭聲 | 「街道喧鬧漸入」、「教堂鐘聲響起」 |
| 🔊 動作音效（Action FX） | 衝擊、移動、碰撞聲 | 武器揮擊、腳步聲、關門聲 | 「甩石破風聲」、「巨人腳步震地」 |
|  | 象徵性聲音 | 象徵情緒或神性事件 | 「天開雷鳴」、「輕風象徵聖靈臨到」 |
| 🗣️ 角色聲音（Voice Cues） | 旁白（Narration） | 描述故事、思想或反思 | 「大衛心中說：神是我的力量。」 |
|  | 對話（Dialogue） | 角色間互動 | 「誰能與我一戰？」 |
|  | 內心獨白（Inner Voice） | 情緒內省 | 「我心裡懼怕，卻仍信靠祢。」 |
| 🎵 配樂（Music Cues） | 背景音樂（BGM） | 鋪陳氣氛、轉場、情感升華 | 「柔和弦樂漸起」、「戰鼓節奏加快」 |
|  | 主題音樂（Theme Motif） | 呼應人物或信仰主題 | 「信心主題重現於高潮段落」 |
|  | 音畫對位（Sync Cue） | 音樂節奏與畫面同步 | 「鏡頭推進時配合鼓點上升」 |

## ⚙️ 二、使用原則（Usage Guidelines）

1️⃣ **每幕可包含 1–2 種聲音層次**  
> 適度即可，避免聲音過多分散注意。  
> 例：「柔和弦樂襯底，遠處鳥鳴點綴寧靜氛圍。」  

2️⃣ **配樂節奏與畫面節奏對應**  
> - 節奏 Level 1–2 → 使用慢節奏弦樂或鋼琴。  
> - 節奏 Level 3–4 → 使用中快節奏、打擊或銅管。  
> - 節奏 Level 5 → 使用鼓、電子音、快節奏配樂。  

3️⃣ **聲音作為敘事輔助，不取代文字**  
> 聲音應補足畫面或情感，而非喧賓奪主。  

4️⃣ **AI 視聽生成提示建議**  
> - Midjourney / Runway 可配合「Audio mood」描述，如：  
>   - calm ambient soundscape, soft choir, subtle cinematic score  
>   - intense battle drums, echoing chants, epic orchestral rise

## 📖 三、範例（Example Integration）

> 🎞️ Scene 6：大衛迎戰歌利亞  
> 【配樂】戰鼓節奏漸強，象徵信心增長。  
> 【音效】風聲與呼吸聲加劇，甩石破風瞬間突顯。  
> 【旁白】「他並不倚靠刀槍，而是倚靠萬軍之耶和華。」

## 🧠 四、設計說明（Design Notes）
- 本文件屬「聲音輔助層」，與分鏡與運鏡模組協同運作。  
- 系統在生成階段自動引用聲音提示，使畫面更具臨場感。  
- 使用者可選擇是否顯示「音效層」於最終輸出（預設為啟用）。
