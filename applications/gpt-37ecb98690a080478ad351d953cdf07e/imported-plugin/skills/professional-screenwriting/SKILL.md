# Professional Screenwriting

Use this Skill only when Professional Screenplay, Fast Draft screenplay, screenplay critique, imported-script bridge, or a targeted script edit is selected. Quick Storyboard goes directly to story-and-creative-development and retains its established approvals; do not require RM-W materials or screenplay approval there. Non-narrative music work has no screenplay obligation.

## Workflow

For a new narrative, recommend Professional and show the direct Quick Storyboard choice. Explicit user choice takes precedence. Gather purpose, genre, audience, length, source truth, intent and constraints, with at most one consequential question per turn by default. Architecture is adaptable, not a mandatory dramatic formula. Write filmable screenplay scenes with stable screenplay/scene/beat/dialogue IDs, estimated timing, action, speaker lines where applicable, and source/imagined labels.

Critique before editing. Anchor observation, editorial inference, alternative hypothesis, verification need, severity, confidence, priority, affected scenes, and references actually consulted. Keep optional craft scores distinct from hard gates; allow N/A or insufficient evidence. Offer alternatives and tradeoffs. An accepted suggestion is `ACCEPTED_NOT_APPLIED`; apply only on explicit authorization for its exact scope. Preserve original/imported text, rejected proposals and history. After application mark `APPLIED_UNVERIFIED`, compare exact before/after revisions, check affected cross-scene dependencies, then mark VERIFIED or REGRESSED as evidence warrants. Give each issue FIXED/PARTIAL/UNCHANGED/REGRESSED/INCONCLUSIVE. Missing context yields bounded critique, never whole-script readiness. Creative quality gains require matched independent human assessment; a local textual correction proves only that correction.

Fast Draft is provisional screenplay, distinct from Quick Storyboard and from approval. An imported complete script may proceed to P5 Critic without overwrite. A report-only R-REPORT is never screenplay approval. For canonical transfer, create a real scene/beat map from the exact script (`SCRIPT_DERIVED`) or a reconciled Beat Sheet (`BEAT_SHEET_RECONCILED`); do not invent prior approvals. Map every required scene and meaningful beat to ordered storyboard shots or an owner-approved disposition. Script scene counts are not storyboard shot counts.

## P7/P8 approval integrity

Present the exact screenplay ID, revision, map and unresolved non-hard issues to the owner. P7 records explicit approval for that exact script and map. P8 has only P7 inbound; failure and resume return to P7 for revalidation. Check source/rights, verified Scripture when triggered, canonical continuity, approval integrity and consultation using the six exact gate IDs, each `PASS | BLOCK | NOT_CHECKED | NOT_APPLICABLE` with reason for N/A. `NONE` and old aliases cannot pass. Recheck current dependencies, map coverage and approval at P8. A changed approved script creates a revision and selectively stales dependent artifacts. Director Project approval, production approval and external action authorization remain separate.

When local command execution and bundled-file access are available, follow [the guard runtime contract](references/Screenplay_Guard_Runtime_Contract.md). Resolve the installed plugin root from this Skill's location and invoke the bundled guard entrypoint specified in the runtime contract with Python 3.10+ using an argument vector (no shell interpolation). Send one structured JSON object on stdin and parse JSON stdout. This file path is relative to the current installed plugin, never a copied Windows or Linux machine path. The declared manifest entry is not a callable tool by itself. Use `p7-check` for exact owner approval and source-anchored scene/beat map (shot IDs are not required); retain its structured identity and evidence digest. Before P8 drafting, independently assemble current evidence and use `p8-entry-check` with that P7 result, then use `p8-draft-check` on the actual draft shot/disposition map. The P7 map digest and P8 shot map digest are distinct. Tool bindings: screenplay-guard-p7, screenplay-guard-p8-entry, screenplay-guard-p8-draft. `revision-check` remains available. Legacy `bridge-check` blocks ambiguous calls. Inspect `status` and `issues`, not just process exit code. If invocation, evidence, or result parsing is unavailable, report NOT_VERIFIED and hold the protected step. The helper cannot judge dramatic quality, authenticate owner provenance, or prove reference reading merely from a supplied record. No external provider or paid generation is needed for this text workflow.
