## 1. Scope and rights discipline

This document specifies **behavior-level** consultation; Workbench alone chooses physical Skill bindings, paths, loaders, storage, indexing/RAG and adapters. No reference must be consulted for an irrelevant task. Consultation means **actual reading + application of distinctive knowledge**, not a static file match or naming a reference in an answer. For a required inaccessible material, issue `REFERENCE_CONSULTATION_UNVERIFIED`, restrict only dependent claims or protected actions, retain safe partial output and log the missing evidence. `REFERENCE_CONSULTATION` gate is defined by the six-ID Canonical Gate Registry.

Five rights dimensions are separate: **inspection, internal transformation, redistribution, exact quotation, and derivative/publication**. Possession/access alone does not confirm permission. User scripts and scripture translation licensing are per-project rights decisions.

### Cross-cutting references and exact sources

A **project-specific actual Scripture passage** is an additional source, *not* one of the 20 packaged Reference IDs. For Bible-source exactness, check the actual named passage/translation under the project's permissions; RM-S02 alone is an evaluation rubric and cannot prove verbatim wording. External third-party imported scripts have independent inspection/transformation/redistribution rights; report-only private critique and derivative republication have different eligibility.

**Explicit bypass:** User chooses `QUICK_STORYBOARD` → apply original S/C reference obligations as task-relevant, never automatically require RM-W01/W02/W03 or SW-G2. A non-narrative poem/music montage with no narrative scene/reveal/dialogue dimension may record RM-W02 `NOT_APPLICABLE`. A *silent but dramatic* scene uses RM-W02 visual-causality and reveal rules while setting **dialogue** assessment `NOT_APPLICABLE`.

## 4. Operational Consultation Record — evidence contract, not file/storage specification

For **every material and workflow decision where a reference is required**, record at least:

```yaml
consultation_id: RC-EX-001
reference_id: RM-W02
resolved_version_or_sha256: "<exact version or digest actually inspected>"
workflow_stage: WF-SW-PRO/P4
logical_behavior: IM-SW-03
trigger_reason: "Visual scene turn and reveal scheduling for a silent scene"
consultation_required: true
actual_access_evidence: "<inspectable tool/log event or source-read provenance>"
knowledge_applied: "RM-W02 silent scene causal turn: action changes encounter outcome"
output_anchor: "SC02/B03"
consultation_state: READ_APPLIED
limitations: "Dialogue score NOT_APPLICABLE; actual viewer response unverified"
source_rights_status: "Internal review allowed; external redistribution not inferred"
```

Permitted `consultation_state`: `READ_APPLIED` (evidence of both actual content access and proper task-specific use), `READ_NOT_APPLIED` (read observed, no demonstrable application), `NOT_READ`, `UNAVAILABLE`, `NOT_APPLICABLE` (with trigger-specific reason), `UNVERIFIED_ACCESS` (answer refers to a source but observable access evidence absent). `READ_APPLIED` alone still requires a **semantic evaluator** to determine whether the knowledge was used *correctly*. No provenance = no claim of actual consultation; do not mark `REFERENCE_CONSULTATION=PASS` based only on reference name, a packaged index, or creative success. A failed required consultation blocks **the protected dependent decision**, not an unrelated safe report.

A **Consultation Statement** aggregates only records triggered by the current path. It must identify which were required vs optional, read/applied/unavailable and relevance, and never imply all 20 were accessed during one task. For `REFERENCE_CONSULTATION=PASS`, all triggered mandatory references need sufficient records for the requested action and no material misapplication; otherwise `NOT_CHECKED`/`BLOCK` with reason. Approval/rights/source gates are separate.

## 5. Conflict precedence and fallback

- Bible-source facts and exact passage wording outrank generic RM-W craft proposals. RM-S01/S02 support Bible setup/review; an explicitly verified translation passage provides exact text evidence. Mark imagined dialogue as invented.
- RM-W02 scene craft is **not** RM-C07 output-format authority; RM-C01 visual edit rhythm is **not** narrative timing or RM-W02 dramatic beats.
- RM-P01/P05 preserve established canonical project/scene semantics and approval. SW-01 screenplay is a governed component, not parallel rival project authority.
- RM-P03 provides a method for assessing target capability but not current vendor capabilities; external source/runtime evidence is still needed. RM-P04 governs L3 execution evidence and requires authorization.
- Missing reference: mark `REFERENCE_CONSULTATION_UNVERIFIED`, retain original versions, continue only non-reference-dependent suggestions; do not fabricate quotes, approval, provider support or tests.
