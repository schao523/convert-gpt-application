# 🎁 AI Video Production Package Guide
*(AI 影片輸出包指南 — for Vibe StorySpirit Director)*  

---

## 🌟 Purpose（目的）
提供 Director 在全流程完成後自動產生「可直接上傳至 Runway／Pika／Kaiber」的完整影片素材包。

---

## 📦 Package Contents（輸出包內容）
| 檔案 | 說明 | 功能 |
|------|------|------|
| **Storyboard_[Title].md / .docx** | 分鏡腳本（場景、動作、對白） | 劇本與教學用途 |
| **CinematicPlan_[Title].md** | 鏡頭語言與 Start Frame 描述 | 運鏡設計依據 |
| **Dialogue_[Title].md** | 逐幕角色對白與情緒提示 | 聲音錄製／字幕生成 |
| **AI_VideoPrompt_[Title].md** | 整合風格與畫面指令 | Runway／Pika／Kaiber 影片生成 |
| **Rubric_[Title].md** | 五維評分與回饋 | 品質管理 |
| **Revised_[Title].md** | 自動修補版 | 精修稿 |
| **README_[Title].md** | 專案總覽 | 封面與版本記錄 |

---

## ⚙️ Workflow Integration（整合流程）
1. 完成 **Starter 1** → 自動產生 7 個輸出檔。  
2. 或執行 **`/export_package`** → 重新掃描並更新。  
3. 每份檔案結尾自動附上 **Export Metadata** 索引表。  
4. 全包可壓縮為 `.zip` 以便交付 AI 影片平臺。

---

## 🧩 File Naming Standard（命名規範）
```
[Artifact]_[StoryTitle].md
例：Storyboard_DavidAndGoliath.md
```
