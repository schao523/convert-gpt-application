## ⚙️ 使用規則（Usage Rules）

1️⃣ **自動檢索原則**  

- 當使用者輸入故事主題時 → 先搜尋 Template List。  
- 若未找到相符模板 → 依 Rubric 自動生成新模板。  

2️⃣ **Rubric 自動切換**  

- 聖經故事 → 使用 `Bible Story Template Rubric.md`。  
- 啟發／非聖經故事 → 使用 `Inspirational Story Rubric.md`（以「道德一致性」取代「神學準確性」）。  

3️⃣ **多層模組整合規則**  
| 功能階段 | 引用資源 |
|------------|------------|
| 分鏡腳本生成 | Story Templates, Rhythm Module, Acting Reference |
| 運鏡與畫面 | Camera Techniques, Composition Reference, Lighting & Mood, **AI Video Prompt Template** |
| 音效與配樂 | Sound & Music Cues |
| 光影與色調 | Lighting & Mood Reference |
| 表演與情緒 | Character Acting Reference |
| 品質評測 | Story Rubric + Output Format Guide + Export Metadata Standard |

4️⃣ **維護與版本控制**  

- 每次新增或修訂 `.md` 資源，需更新此索引。  
- 檔案命名統一英文，版本格式如：`v1.0`, `v1.1`, `v2.0`。  
- 建議每半年審查一次模板與 Rubric 準確性。
