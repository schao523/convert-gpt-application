# 🎥 Camera Techniques Glossary  
*(鏡頭運動與構圖術語表 — 導演專業支援用)*

## 🎯 目的（Purpose）  
本文件提供動畫／影片製作時常用的「運鏡術語」與「構圖用法」參考。  
由 Director GPT 用於生成 **運鏡說明（Camera Direction Summary）** 時，確保專業性與一致性。  

---

## 🎬 鏡頭運動（Camera Movements）

| 術語 | 英文對應 | 用法說明 |
|------|------------|-----------|
| **推進** | Dolly In | 鏡頭向前移動以加強情緒或聚焦角色。 |
| **拉遠** | Dolly Out | 鏡頭後退以展現環境或表現孤立、退縮。 |
| **平移** | Pan / Track | 鏡頭左右移動以追隨動作或揭示新元素。 |
| **俯拍** | High Angle | 鏡頭從上往下拍，製造弱勢、渺小感。 |
| **仰拍** | Low Angle | 鏡頭從下往上拍，強調威嚴或力量感。 |
| **環繞** | Orbit / 360 Shot | 鏡頭繞角色旋轉，增加戲劇張力或情感流動。 |
| **跟隨** | Follow Shot | 鏡頭跟著角色移動，增強臨場感。 |
| **搖鏡** | Pan / Tilt | 水平或垂直旋轉鏡頭以展示全景或焦點。 |
| **定鏡** | Static Shot | 鏡頭固定不動，聚焦角色內心或靜謐時刻。 |
| **推軌特寫** | Dolly Close-Up | 結合移動與特寫，強化情緒爆發點。 |

## 🧱 構圖技巧（Composition Techniques）

| 術語 | 英文對應 | 用法說明 |
|------|------------|-----------|
| **特寫** | Close-Up | 聚焦角色表情或關鍵物件。 |
| **中景** | Medium Shot | 呈現角色互動與身體語言。 |
| **全景** | Wide Shot | 建立場景或故事環境背景。 |
| **深景構圖** | Deep Focus | 前景與背景皆清晰，營造空間層次。 |
| **逆光** | Backlight | 用光影對比傳達戲劇性或象徵意涵。 |
| **剪影** | Silhouette | 以暗影呈現人物輪廓，表達神秘或內心轉折。 |
| **柔焦** | Soft Focus | 模糊背景以強調主角或營造夢幻氛圍。 |
| **快速切換** | Quick Cut | 增強緊張感或節奏感。 |
| **慢動作** | Slow Motion | 延長關鍵時刻，放大情感張力。 |
| **空鏡頭** | Empty Frame | 無人物的畫面，象徵孤寂、思考或轉場。 |

## ⚙️ 建議使用規則（Usage Rules）

1️⃣ **生成原則：**  
每一幕的「運鏡說明」應包含 1–2 種鏡頭術語，並配合敘事情緒。  

2️⃣ **組合範例：**  
- 「推進 + 特寫」→ 情感聚焦場景  
- 「平移 + 全景」→ 場景開場或轉換  
- 「仰拍 + 環繞」→ 展現力量、勝利  
- 「俯拍 + 空鏡頭」→ 象徵孤單或反思  

3️⃣ **風格匹配：**  
- 兒童動畫 → 使用簡潔動作（推進、平移、特寫）  
- 青少年動畫 → 強調節奏與角度變化（環繞、拉遠、慢動作）  
- 成人敘事 → 使用象徵性構圖（逆光、剪影、深景構圖）  

4️⃣ **對應模組：**  
由「運鏡與起畫支援模組」自動引用，用於：  
- 運鏡說明生成  
- Start Frame 描述精修  
- AI Prompt 強化（畫面語意層次）
