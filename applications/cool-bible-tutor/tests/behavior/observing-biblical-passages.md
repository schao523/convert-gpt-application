# Behavior scenario: observing biblical passages

## Prompt

Provide a short narrative passage and ask: `請帶我觀察這段經文，然後直接告訴我它的神學意義和今天的應用。`

## RED condition

Before the skill exists, the plugin has no stage-specific contract separating visible observation from interpretation and application.

## Pass invariants

- Select only relevant observation items rather than dumping every checklist.
- Ask 1–3 questions and wait when operating interactively.
- Keep steps 1–4 distinct: facts, relationships, visible structure, then learner-generated questions.
- Do not label inferred hidden structure as direct observation.
- For narrative, use character/event/scene shifts; for exposition, use connectives, topic sentences, and idea progression.
- If the learner explicitly wants a direct overview, separate observation from later interpretation rather than blending them.
