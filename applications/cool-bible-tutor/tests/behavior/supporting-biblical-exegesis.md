# 八種處境釋經支援技能行為情境

## 基準失敗情境

提出一個史地文化問題。未受約束的回應容易傾倒全部八種處境、虛構背景資料，或用未標示證據層級的長篇講解取代學員查考。

## 通過準則

- 每次只選最有解釋力的一至兩種處境，清楚標名並說明選擇理由。
- 先以文本出現次序作基本檢查，再按問題需要選用其他處境，不機械套用全表。
- 背景、原文、互涉與人物資料都區分已知證據、合理推論與未知；不可虛構。
- 文體分析遵守敘事、律法、詩歌、智慧、預言、書信與啟示文學各自限制。
- 救恩歷史正確使用六階段，並以有經文根據的方式連於基督，不把每個細節任意寓意化。
- 輸出回到目前觀察或解釋階段，提出相應問題並等待，而不是變成無關講座。
