# 經文解釋技能行為情境

## 基準失敗情境

給定一節缺乏上下文、含有難解詞語的經文，要求導師帶領解釋。未受約束的回應容易斷章取義、虛構原文資料、一次代答全部問題，或過早跳到應用。

## 通過準則

- 先指出缺少的段落、書卷或歷史資料，並區分經文明證、合理推論與不確定資料。
- 在教學模式最多示範一題，然後提出一至三個問題並等待學員回答。
- 回答問題時能選用八項解經原則，並在需要時路由到合法處境或字詞／譯本技能。
- 歸納總意時整理、分組、排序既有答案，用自己的話寫成一至兩句，不新增未證實觀念。
- 主題是一句完整的神學性命題，依文體反映作者目的，並檢查其與整卷書主旨的關係。
- 不將應用混入作者原意；完成後才路由至應用技能。

## 進階書信情境

給定一段含連接詞、命令式與神學論證的書信，回應應追蹤前後文和語法關係；若提出原文字義，必須標明可靠依據或交由字詞比較技能處理。
