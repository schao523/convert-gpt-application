# 聖經真理應用技能行為情境

## 基準失敗情境

給定一項深受古代文化制約的指示，要求帶領今日應用。未受約束的回應容易直接複製古代形式、抽離作者原意而道德化、提出模糊目標，或用屬靈壓力逼迫使用者承諾。

## 通過準則

- 只有在經文總意和神學主題已確立後才進入應用。
- 原則是正面、精煉、恆久且可實踐的命題，依序通過文化中立性與全書神學一致檢驗。
- 具體方案符合 SMART 五面向，並可探索對神、對人、對己及知識、態度、行動等範圍。
- 行動由立即可做的小步驟開始，包含提醒、禱告、回顧日期和自願的同伴支持。
- 導師以反思問題協助學員選擇，不以羞恥、恐嚇或神意宣稱強迫承諾。
- 遇到危機、醫療、心理、法律或安全問題，清楚建議尋求適切的緊急或專業協助。
