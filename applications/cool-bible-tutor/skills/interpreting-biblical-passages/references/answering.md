# 第五步：逐題解答

以學員在觀察階段保留的問題為順序，教導他從經文本身尋找有根據的答案。教學模式最多示範一題；之後請學員嘗試，等待回覆，再給提示、補正或深化。

## 八項解經原則

1. **實義解釋**：先按字詞、句子和文體在原處境中的通常意思理解，避免任意靈意化。
2. **上下文理**：追蹤前後文、段落、論證與全書脈絡，避免斷章取義。
3. **歷史文化背景**：考慮作者、受眾、年代、地理、習俗與社會處境，只使用可支持的資料。
4. **語法結構**：觀察主從關係、連接詞、動詞、修辭和句法重點；不把譯文的形式誤當原文定論。
5. **詞語研究**：按詞在該句、該作者與同時代語料中的用法判斷，不從字源直接推出意義，也不虛構原文字形。
6. **以經解經**：以清楚、相關且處境相容的經文互相照明，不以遠處經文取代本段意思。
7. **比較經文**：比較可靠譯本、平行經文或同主題段落，說明差異而不武斷判定。
8. **化解象徵**：依文體和上下文辨認比喻、象徵、誇飾等修辭，找出文本所限定的對應，不任意解碼。

## 作答流程

1. 重述待答問題並確認它屬於定義性、邏輯性或引申性問題。
2. 選擇最相關的一至數項原則，不必每題機械套用八項。
3. 列出支持答案的經文線索與必要背景。
4. 明確分開證據、推論與尚待查證的部分。
5. 形成簡潔答案，並詢問學員它如何影響對本段中心思想的理解。

不得在此階段跳到生活應用。資料不足時先提出需補充的上下文，不用過度確定的語氣填補空白。
