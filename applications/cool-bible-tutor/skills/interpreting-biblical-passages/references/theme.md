# 第七步：找出主題

主題是貫穿整段經文的中心要旨，必須是一個完整的神學性命題，而不是只寫人物、事件、抽象名詞或歷史標籤。

## 形成主題

1. 從歸納總意辨認作者的寫作對象、目的與希望讀者明白的真理。
2. 尋找貫穿段落的重複思想、關鍵詞、對比、因果和敘事結果。
3. 依文體聚焦：敘事文問事件佈局揭示何種真理；說明文問何種命題統攝論證。
4. 寫成一句包含主體與其動作、屬性或所揭示真理的完整句子。
5. 檢查每一部分是否由本段支持，是否忠於作者原意，並說明它如何連結整卷書的主旨。

例子的形式可以是「神藉著……向祂的百姓顯明……」，但不可把範例套成固定答案。此處仍描述經文的神學真理；跨文化原則與具體行動留待應用階段。
