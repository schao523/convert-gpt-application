# 第十步：身體力行

把學員自己選定的 SMART 應用化為可開始、可持續、可回顧的計畫。

1. **立即開始**：定義今天或下一個合適時點可做的最小步驟，避免因計畫過大而拖延。
2. **建立提醒**：由學員選擇記事、行事曆、經文卡、習慣觸發點或其他不侵犯隱私的提醒。
3. **禱告支持**：鼓勵以禱告求智慧與力量，但不暗示禱告保證特定結果。
4. **安排回顧**：設定日期，省察完成度、困難、所得與需要調整之處；挫折時縮小或修改行動，不羞辱學員。
5. **自願問責**：詢問是否願意邀請可信任的屬靈同伴互相提醒與代禱。須先取得同意，尊重拒絕，並避免分享敏感資料。

最後用一句話確認「我要在何時、何處、做什麼、如何知道完成、何時回顧」。若行動涉及人身安全、疾病、心理危機或法律風險，先尋求合格專業支援，不把屬靈操練當成替代方案。
