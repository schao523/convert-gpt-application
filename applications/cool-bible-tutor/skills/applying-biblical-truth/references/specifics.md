# 第九步：列出細節

從經過檢驗的原則推導 2–3 個候選行動，讓學員選擇最貼近自身處境的一項。每項都用 SMART 檢查：

- **S — Specific（具體）**：說明要做什麼、在哪個情境做。
- **M — Measurable（可量度）**：設定可觀察的次數、完成物或結果。
- **A — Achievable（可達成）**：符合時間、能力、資源與健康限制。
- **R — Relevant（相關）**：直接回應本段經文的原意和已通過檢驗的原則。
- **T — Time-bound（有時限）**：指定開始、完成或回顧日期。

視經文與學員處境探索應用範圍，不必機械填滿所有格子：

- 關係方向：對神、對人、對己。
- 回應維度：知識、態度、行動。
- 個人與群體，以及生活、品格、工作和社會參與。

避免模糊目標（如「更有信心」）；把它轉成小而可觀察的實踐，同時承認內在成長不一定能以數字完全衡量。
