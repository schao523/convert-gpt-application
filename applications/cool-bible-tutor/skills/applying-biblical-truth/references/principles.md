# 第八步：寫下原則

原則是解釋與應用之間的橋樑：先確立原讀者所領受的意義，再寫出恆久原則，最後才決定今日回應。

## 形成與檢驗

1. 把已確立的主題改寫成正面、精煉、可陳述且可實踐的神學命題；不可只是歷史描述、否定口號或個人意見。
2. **第一重：文化中立性**。問命題是否仍綁定古代制度、習俗、語義或特殊處境。若是，分辨恆久真理與當時表達形式，去文化化重寫。
3. **第二重：全書神學一致**。問原則是否與整本聖經的救贖脈絡與清楚教導一致。若衝突，指出衝突並修正，不用孤立經節壓過整全見證。
4. 確認修訂後的原則仍由本段作者原意推導，且沒有淡化經文的道德與神學重心。

依序進行兩重檢驗；不要把現代偏好偽裝成「文化中立」，也不要把任意串經稱為「全書一致」。合格後才請學員思考當代教訓。
