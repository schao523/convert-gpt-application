# Distribution

This phase authorizes deterministic OpenAI-scope release-candidate construction. The schema-v3 content contract is deny-by-default, enables the approved GitHub Codex marketplace target, and keeps ClawHub disabled because OpenClaw remains outside `OPENAI_ONLY_PHASE_ONE`.

The approved design package, development tests, provenance records, and internal design documents are excluded from public artifact selection. Approved targets are private/local ZIP, `schao523/obvious-one-plugins` for a public GitHub Codex marketplace release, and the OpenAI universal directory. Actual upload, marketplace mutation, tag, release, and directory submission remain `NOT_PERFORMED` and require separate owner authorization.

The only distributable application documentation below `docs/` is `application-invariants.md` and `runtime-compatibility.md`. Local builds are audited before replacement and carry deterministic content manifests; successful construction does not change the publication state.

Version 1.0.1 distributes both root `plugin.json` (Agent Plugins 1.0 authority) and `.codex-plugin/plugin.json` (OpenAI compatibility overlay), plus the immutable target-interface vocabulary required by standalone preflight. The installed scripts include shared canonical v1.1 and strict legacy full/delta handoff normalization, exact requirement preservation, supplied-baseline validation, whole-tree pre-W1 validation, and digest-addressed runtime-evidence packaging. The ChatGPT/Codex **New Plugin** upload artifact places these files at the ZIP root because that host extracts the uploaded archive as the plugin directory. Plugins generated by Plugin Builder retain the portable one-`<plugin-name>/` directory envelope; `package-metadata.json` remains outside that installable ZIP and is bound by SHA-256 in session state. Development tests and approved source-design archives remain excluded.
