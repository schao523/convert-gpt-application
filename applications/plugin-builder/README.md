# Plugin Builder

Plugin Builder converts an approved application-plugin design package into a locally validated OpenAI plugin workspace and deterministic candidate artifact. Version 0.1.0 establishes the phase-one identity, provenance, policy, and runtime boundary; later implementation tasks add the four workflow skills and deterministic session contracts.

Phase one targets Codex and ChatGPT Work Local/Desktop. OpenClaw and Claude are explicitly out of scope. No marketplace publication, external release, account deployment, credential handling, semantic RAG, or network service is authorized.

Approved design files are internal implementation inputs and are not selected for distribution.
