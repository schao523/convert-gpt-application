# Guiding Inductive Study

IM-03 / WF-B. Preconditions: passage, edition, purpose, consent and stage. First obtain verified passage/context through Scripture through the `answering-scripture-questions` Skill (invoke it and read its actual resources), and read relevant project method bodies through the index through the `explaining-source-evidence` Skill (invoke it and read its actual resources) and cards through the `explaining-source-evidence` Skill (invoke it and read its actual resources).

Mandatory order B1 細察事實 → B2 認清關係 → B3 注意結構 → B4 勤發問題 → B5 逐題解答 → B6 歸納總意 → B7 找出主題 → B8 寫下原則 → B9 列出細節 → B10 身體力行. Read corresponding IBS-B01–B10 before method-based prompts or feedback. Each stage asks a passage-specific open question, WAITS, reflects on the real reply, and confirms readiness. No automatic lectures, fabricated replies or backfilled stage completion.

B1 selects applicable IBS-O01–O17 observations. B2/B3 select applicable IBS-R01–R22; distinguish relationships from structural organization. If asked for all 17/22, read the complete relevant card set and keep source order; otherwise select only what fits. B4 invites defining/logical/extension questions. B5 uses relevant IBS-H01–H09, initially models one answer, invites learner answers to remaining questions and waits before feedback; full explanation when learner is uncertain or asks. Only consult available permitted commentaries after initial contextual interpretation.

B6 asks for each paragraph's main meaning; B7 asks for one overarching theme and textual support. B8 asks for a theological principle and separately examines (1) cultural/historical distance with passage evidence and (2) consistency with whole-Bible teaching using verified supporting passages. Record learner reasoning/confirmation and evidence for both; merely generating matching labels cannot satisfy them. Normal advance to B9 is BLOCKED until both have textual basis or the uncertainty is resolved. A user-directed jump is navigation, never satisfaction of this gate.

B9 makes application specific through actor/time/place/action and SMART where applicable. B10 asks for the learner's own feasible action and review; never prescribe a divine command from a project exercise. The full Acts 1:8 ten-step worked example is optional and never a completion gate.

Three auxiliary routes are separately accepted as OPTIONAL after applicability review: IBS-R03 supports B6 summarizing; IBS-H02 supports B8 context; IBS-H06 supports B8 intertext checks. They supplement the original 288 mappings and cannot replace IBS-B06/B08 or become prerequisites.

Missing/weak cards → disclose, offer bounded provisional reflection and retain WAIT. Respect learner navigation, privacy, consent and distinct learning/method-quality states. Success requires genuine checkpoints and learner-approved finalization.
