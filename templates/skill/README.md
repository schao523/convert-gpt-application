# Skill template

Use `skill-creator` for each capability extracted from the approved coverage
matrix. A skill owns activation guidance and workflow instructions; reusable
computation and retrieval belong in supporting tools.

Put approved professional knowledge in the owning skill's `references/`
directory, directly link it from `SKILL.md`, and state when it must be read. Put
approved general knowledge under one application-specific consultation skill
with a `references/knowledge-index.json` topic guide.

Do not create an empty `references/` directory.
Do not create `knowledge-index.json` unless the application has approved general knowledge
that needs the shared consultation route. Existing references require explicit
classification and product-owned behavioral scenarios before migration.
